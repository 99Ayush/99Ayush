## 🌀 What kind of builder am I?

I don’t just write code that works. I design **systems where the LLM only reads**, the **math is visible**, and **“I don’t know” is a first‑class answer**.

- **Deterministic over clever** – Every rupee, every slab, every tax figure is computed by plain JavaScript with a formula you can audit.
- **Privacy is an ordering problem** – PII gets redacted before it leaves the machine. Raw documents never reach a third‑party API.
- **Abstention is an answer** – If the evidence isn’t there, the verdict is “I couldn’t find it”. No guessing.
