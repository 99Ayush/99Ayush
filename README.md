## 🎯 What I do

I build full‑stack products from empty repository to deployed URL. I’m obsessed with the bits most people skip:

- **Deterministic over clever** – Salary math is plain JavaScript with a visible formula behind every number.
- **Privacy is an ordering problem** – PII gets redacted before it leaves the machine; raw documents never reach a third‑party API.
- **Abstention is an answer** – “I could not find evidence” is a first‑class verdict, not a guessed true/false.
